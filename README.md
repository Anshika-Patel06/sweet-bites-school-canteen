# 🍰 Sweet Bites – School Canteen Menu

## 🌸 About the Project

Sweet Bites is a simple school canteen menu website where students can view the food menu for different days of the week.

## ✨ Features

- View weekly menus from Monday to Saturday.
- Select a day using the dropdown menu.
- Click the View Menu button to display the selected day's menu.
- Check food items and their prices.
- View canteen opening and closing timings.
- Attractive pink and lavender-themed design.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 📂 Project Files

- `index.html` – Contains the structure and content of the website.
- `style.css` – Contains the styling and design of the website.
- `README.md` – Contains project documentation.

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Select any day from the dropdown menu.
5. Click **View Menu** to see that day's food menu.

## ⏰ Canteen Timings

9:00 AM – 3:00 PM

## 🎯 Learning Outcomes

- Understanding HTML structure.
- Applying CSS styling.
- Using JavaScript functions.
- Learning DOM manipulation.
- Handling button clicks and dropdown selections.
